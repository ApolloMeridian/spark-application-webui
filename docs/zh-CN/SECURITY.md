# 安全策略

## 报告漏洞

请使用本仓库 GitHub 的私密漏洞报告功能。不要在公开 Issue 中包含利用细节、密码、令牌、集群地址或其他敏感信息。请提供受影响版本、部署模式、复现步骤、影响和建议缓解措施。维护者通过私密报告协调修复与披露。

## 部署责任

- 将数据库密码、本地管理员密码与 OIDC 客户端密钥保存到 Kubernetes Secret。
- 对外开放控制台前配置 TLS。
- 限制 Kubernetes RBAC 与监控命名空间。
- 保护 Prometheus、Loki、PostgreSQL 和身份提供方的网络访问。
- 配置或日志泄露凭证后及时轮换。
- 部署前核对容器镜像来源与部署配置。
- 备份 PostgreSQL，它保存身份、审计、工作流与调度状态。
